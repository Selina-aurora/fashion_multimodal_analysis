## 这次实际做什么

1. 原图自动检测所有人的肩、肘、腕；保留全部人物和两侧手臂。昨天的结果只保留人工辅助选中的臂，不能直接替代本次全自动关联，所以这里重新执行姿态前向推理。
2. 使用已有 Mask R-CNN 在原图预测服饰框和实例 mask，不读人工框、人工 mask 或袖长标签参与推理。
3. 对每个预测为 top / outerwear / dress 的实例，按预测框覆盖、肩部位置与几何关系自动匹配人物。多人接近时允许拒绝匹配。
4. 分别处理该人物的两侧臂，不用人工点位选择最佳臂。检查置信度、图像边界、臂段长度和明显折叠姿态。
5. 沿肩—肘—腕折线，使用三种窄条宽度搜索预测服饰 mask 到背景的稳定过渡，提出袖口位置。没有可靠边界时返回 null，不硬算长袖或无袖。
6. 袖长比例 = 肩到预测袖口的沿臂路径长度 / 肩到腕的路径长度。
7. 保存自动预测后，才读人工标注，按 GT 服饰框 IoU 匹配预测实例并对照人工标注侧，计算误差。GT 匹配只用于评估，不回写、更换或修正自动预测。

这里的“全自动”指推理环节没有人工选择人物、手臂或袖口，不表示模型已经达到准确率要求。袖口模块是首版几何边界启发式，需要这次逐图验证；贴身手臂、遮挡、叠穿、宽松袖、无袖和落肩可能失败。输出的匹配与边界分数是启发式分数，不是校准概率。

## 结果怎么读

- `summary.json`：实例匹配数量、手臂覆盖、有效比例输出数量、关键点误差、袖口误差、袖长 MAE/RMSE、失败类型。
- `per_case.csv`：8 条逐例比较，包含自动匹配到的人物和解剖侧、类别偏差、各关键点误差、袖口误差与比例偏差。
- `predictions.json`：评估之前冻结的全部自动实例与两侧臂结果、失败原因、mask 搜索曲线。
- `pose_all_predictions.json` / `segmentation_all_predictions.json`：上游完整预测。分割置信度阈值 0.4，mask 阈值 0.5；与既有配置一致。
- `visuals/`：原图对照。橙色为预测服饰框，青色为预测手臂，红点为预测袖口，绿色为人工服饰框和四点。人工信息仅在这一步绘图。
- `manual_review.csv`：逐例确认服饰、人物、手臂是否匹配正确，以及预测边界是否真的是袖口。该表是事后审核，不是推理输入。
- `run_metadata.json`：权重/代码哈希、输入口径、参数、冻结 CSV 前后哈希。

关键点误差按整图对角线归一化；袖口同时报告像素、对角线比例及人工臂长比例。PCK@0.05 对角线仅是描述性指标，不代表老师已经认可该阈值。平均误差都只针对能比较的样本，必须与覆盖率和失败数一起看，不能把拒绝输出的样本忽略后宣称成功。

每张图目前只有一侧人工标注。因此两侧都自动输出，评估仅统计人工标注的那侧；另一侧不能在没有标注时计算准确率。多人匹配准确率还要结合逐图审核，不能用“成功输出了人物 ID”代替“匹配正确”。

这 8 张来自已反复审核的开发样本，不是独立盲测。不得在它们上反复调参后把结果当泛化成绩。此包不做软标签训练，也不改变此前关于软标签工作的完成状态。
