# PRD 3.1.3 Predicted ROI Attribute Propagation Pilot v2

## 1. Objective

This experiment evaluates whether the predicted ROIs generated by the PRD 3.1.1 instance segmentation model can be directly propagated into the PRD 3.1.3 attribute extraction pipeline.

The purpose is to analyze the influence of ROI prediction errors on downstream attribute extraction.

This experiment measures propagation consistency between GT ROI and predicted ROI outputs, rather than attribute accuracy against human annotations.

## 2. Experimental Setup

### ROI Generation

- Instance segmentation model: Mask R-CNN v3-B1-dataexp
- Checkpoint: outputs/prd_instance_segmentation/maskrcnn_8class_v3_b1_dataexp/checkpoint_last.pth
- Device: CUDA

### ROI Matching

Predicted ROIs were matched with GT instances using one-to-one matching.

Matching criteria:

bbox IoU >= 0.5

GT information was only used as comparison keys:
- source_image
- garment_id

Attribute extraction input remained predicted ROI artifacts:
- predicted crop
- predicted mask

## 5. Analysis

### Primary Color

Primary color achieves complete consistency (12/12 agreement), indicating strong robustness after replacing GT ROI with predicted ROI.

### Pattern

Pattern consistency is lower (7/12 agreement). Pattern prediction is sensitive to ROI variation because it depends on local texture information and fine visual details.

### Fine-grained Structural Attributes

Neckline shows the lowest consistency (1/7 agreement). Fine-grained attributes are more affected by ROI boundary changes.

### High-level Attributes

Silhouette fit and fashion style maintain relatively stable consistency (75.0%), indicating better robustness to ROI variation.

## 6. Conclusion

The experiment validates the interface between PRD 3.1.1 predicted ROI generation and PRD 3.1.3 attribute extraction.

The predicted ROI outputs can be consumed by downstream attribute modules without requiring GT crop or mask information.

The pilot results show:
- Color attributes are highly robust.
- Global visual attributes maintain relatively stable predictions.
- Fine-grained attributes such as pattern and neckline are more sensitive to ROI quality.

The current evaluation is a pilot analysis with limited matched samples and incomplete category coverage. It should not be considered as the final 8-class acceptance benchmark.

Future work:
1. Expand matched ROI evaluation scale.
2. Improve small-region localization quality.
3. Analyze category-specific error patterns.
