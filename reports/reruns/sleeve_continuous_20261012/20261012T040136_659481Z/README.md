## 试验怎么比较

1. 校验 23 张原始图片的 SHA256；从原图裁剪人工服饰框，绝不把画有黄色框、红色框或人工点位的审核图输入模型。
2. 离线提取冻结 CLIP ViT-B/32 的单位长度图像特征，附加同一侧别标量（左 -0.25，右 +0.25）。两个头使用完全一致的输入和记录。
3. 六类头：对六维 one-hot 目标做线性岭回归，取最大得分类别；连续头：对二维可见袖长比例做线性岭回归，预测裁剪至 [0,1]。两者均固定 alpha=0.1，有截距，无开发集调参、无数据增强。
4. 连续结果的六类阈值，仅由各训练类别比例中位数的相邻中点产生。六类预测转连续量时仅使用对应训练类别的均值。不能把人工比例喂给图像预测器。
5. 同时记录训练多数类和训练均值基线，输出准确率、固定六类 macro-F1、混淆矩阵、MAE、RMSE 和逐例预测。
6. 人工比例经同一阈值分档，单列为标签一致性诊断。类别与二维比例有交叠，该数字不代表模型准确率。

该比较控制了特征、样本、线性容量和正则强度，但只检验这两个固定线性头；不代表分类或回归方法的最优性能。没有使用旧版模型的不同划分成绩作为公平配对结论。

## 结果边界与软标签问题

这里的连续量是单侧二维可见臂长覆盖比例，不是物理三维袖长，也不是 softmax 置信度或类别概率软标签。它用于检验连续监督是否有用；不能写成“已完成软标签方案验证”。若老师要求的是相邻类别概率分布，仍需另行明确生成规则并开展同数据对照。

开发集可用 9/12 即 75% 是标签覆盖率，不是模型准确率。样本小、类别不均衡，且原开发集曾被使用过；本轮属于探索性开发诊断，没有新增盲测，不能作为 3.1 验收通过的依据。输入仍依赖人工服饰框和人工侧别，不能宣称已解决上游分割和自动侧别的全链路问题。

本包已在助手环境做标签完整性检查及 NumPy 核心逻辑测试；原图、GPU 和现有 CLIP 缓存位于用户机器，因此实际特征提取和实验执行须以返回结果为准。没有在本机模拟模型结果。
