# VQA 多题型独立 Guard / Shadow 协议草案

- 原 PRD 3.2.1 包含属性问答、设计解析、工艺说明、搭配建议。本试验只评估其中少量代表性问题。
- 原三任务 Guard **不能**直接用于仅一次 VQA 调用；本轮所有输出强制 `publish_allowed=false`，禁止自动发布。
- 对任何问答，先验检查目标身份/Mask 的开发集辅助审核状态，但不得把它当成独立正确真值。
- 对图像不能证明的纤维成分和实际工艺，**不可编造事实**；缺乏商品元数据时应说明无法确认。
- 检查目标跨实例串扰、推理信息来源、禁用“红框”工程调试词、无依据确定性断言、问答脱离问题、明显不完整。
- 建议人审分为：准确有据 / 部分正确 / 证据不足但合理拒答 / 错误或幻觉 / 目标无法评估。
- 不允许用单一类别匹配、回答长度、文本等价或 Guard 低风险来代替人工问答准确率。
- 与已有颜色问答 171 条基线相独立，不混合计算官方 85% VQA 准确率；独立 Holdout 持续封存。
