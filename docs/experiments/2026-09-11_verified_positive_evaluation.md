# Verified-positive FULL / ROI / LOCAL Evaluation — 2026-09-11

## 1. Motivation

Earlier random-sample experiments mixed two situations:

1. the queried part was present but localization failed;
2. the queried part did not exist in the image.

To separate these cases, a target-balanced candidate pool was manually screened and only visible, usable positive examples were retained.

## 2. Benchmark

| Target | Cases |
| --- | ---: |
| sleeve | 22 |
| collar | 22 |
| button | 22 |
| zipper | 22 |
| **Total** | **88** |

Benchmark manifest:

- `reports/verified_positive_benchmark/verified_positive_benchmark.csv`

## 3. Conditions

### FULL

Grounding DINO is run on the original image.

### ROI

Grounding DINO is run on the annotation-assisted garment bounding box with a small margin. This is an **oracle diagnostic condition**, not a deployment-time source of ground truth.

### LOCAL

Grounding DINO is run on deterministic target-conditioned local windows inside the garment ROI. The windows are fixed coarse spatial priors and do not use fine-grained target ground truth.

Parameters:

- model: `IDEA-Research/grounding-dino-tiny`
- threshold: `0.30`
- ROI margin: `0.05`
- local enlargement factor: `1.0`
- local NMS IoU: `0.50`

## 4. Automatic result

| Target | N | FULL | ROI | LOCAL |
| --- | ---: | ---: | ---: | ---: |
| sleeve | 22 | 40.9% | 40.9% | 36.4% |
| collar | 22 | 68.2% | 68.2% | 45.5% |
| button | 22 | 18.2% | 18.2% | 9.1% |
| zipper | 22 | 4.5% | 4.5% | 9.1% |
| **Overall** | **88** | **33.0%** | **33.0%** | **25.0%** |

Mean top detected-box area ratio:

| Condition | Area ratio |
| --- | ---: |
| FULL | 0.963 |
| ROI | 0.963 |
| LOCAL | 0.219 |

FULL and ROI predictions are effectively identical across all 88 cases.

## 5. Interpretation

- FULL/ROI prediction coverage is highest for collar, followed by sleeve.
- Button and zipper remain the main small-object failure modes.
- A prediction is not equivalent to correct localization; many FULL/ROI boxes cover most of the garment/image.
- LOCAL substantially reduces box area but does not improve overall prediction coverage.
- The local-crop intervention is therefore reported as a mixed/negative result, not a successful performance gain.

## 6. Manual audit

The benchmark verifies target presence but does not provide fine-grained target ground-truth boxes. Manual quality labels are therefore used:

- `correct`
- `coarse`
- `wrong`
- `missed`

The current audit files are retained as **preliminary** until low-confidence cases are manually confirmed.
