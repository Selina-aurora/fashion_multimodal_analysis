## 训练设置与实现解释

`batch_size=1`、`lr=0.0001`、SGD momentum 0.9、weight decay 0.0005、warmup 1,000 steps；短边 640、长边上限 1,024；seed 20260930；随机水平翻转、AMP 开启，梯度裁剪 10。

每轮无放回遍历入选图片；同一图的八类有效实例一起进入 target，允许不同实例的掩码重叠。这里的“一轮”不能与少量数据上训练 15 个 epoch 等量理解。SQLite 记录图片/实例信息，掩码按需解码，避免预先生成几十万张全尺寸 PNG。每个 DataLoader worker 使用自己的只读连接。

一轮完成 187,311 batches，mean loss 为 0.3058388562，出现 68 次 FP32 重试。重试处理原 batch，防止 AMP 出现非有限损失时悄悄丢掉样本。训练 loss 不是验证准确率，不能作为 PRD 通过证据。

断点记录包含模型、优化器、scaler、epoch 游标、当前累积统计、随机源与数据身份。仅复制一份同名 `.pth` 或重建一份不同字节的 SQLite，不能保证延续同一次训练；恢复步骤会检查这些身份条件。

## 指标分母与时间口径

TP 是定位成功且类别正确的实例；recall = TP / 全部 GT；precision = TP / 预测总数。定位成功但类别错误，仍不算类别正确 TP。平均 mask IoU 只在类别正确的匹配上计算：V8 Core 分母为 166，而不是 400。

`mask_iou_ge_0_85_rate_all_gt` 则使用全部 GT 作分母，V8 为 111/400 = 27.75%。这与 0.8413 的条件平均 IoU 是不同指标。某类没有类别正确匹配时，条件均值为 null，应保留“不可定义”，不能自动填 0 或删掉该类制造更高 macro 均值。

计时设备记录为 NVIDIA GeForce RTX 4090；预热 10 次，计时 5 遍。范围是 RGB 转换、tensor 预处理、设备传输、模型 forward 和筛选后的 CPU 后处理；不包含磁盘读图、GT 解码、指标计算及报告写入。设备同步位于计时边界。此次没有在当前环境复测这些速度。

## 如何读同目录下看似冲突的状态

`training_summary.json` 的 COMPLETED 与 `workflow_status.json` 的 TRAINING_AND_REGRESSION_COMPLETED 是最终记录。`training_progress.json` 是上一次周期性写入，仍可能显示 TRAINING；`failure.txt` 记录之前准备阶段遇到一张无效图的失败，后来在显式记录并排除后完成训练。旧日志原样保留，不把它删除，也不据此把最终结果说成失败。

最终 `formal_acceptance=NOT_CLAIMED`。Core 曾被开发和回归使用，且早期 v3 训练与 Core 有 33 张图片重叠的记录；后续清理不把它恢复为从未使用的盲测集。正式验收仍需独立冻结、审核合格的测试设计。
