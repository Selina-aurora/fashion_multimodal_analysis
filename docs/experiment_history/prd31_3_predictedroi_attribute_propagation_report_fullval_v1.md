# PRD 3.1.3 Full-Validation Predicted ROI Attribute Propagation v1

## 1. Objective

This experiment evaluates whether predicted ROIs generated by the PRD 3.1.1 instance segmentation model can be directly propagated into the PRD 3.1.3 attribute extraction pipeline.

The objective is to analyze how ROI prediction variations influence downstream attribute extraction results.

This evaluation measures propagation consistency between GT ROI and predicted ROI outputs, rather than attribute accuracy against human annotations.

A disagreement indicates that the predicted ROI changes the downstream attribute prediction compared with the corresponding GT ROI input.

---

## 2. Experimental Setup

### ROI Generation

- Instance segmentation model: Mask R-CNN v3-B1-dataexp
- Checkpoint: outputs/prd_instance_segmentation/maskrcnn_8class_v3_b1_dataexp/checkpoint_last.pth
- Device: CUDA

The predicted ROI artifacts were generated from model predictions, including:
- predicted crop
- predicted mask

GT crops and masks were not used as attribute extraction inputs.

## 5. Analysis

### Primary Color

Primary color achieves high consistency (83.3%), indicating robustness to ROI replacement.

### Pattern

Pattern achieves 77.8% agreement. It is more sensitive because it depends on local texture and fine visual details.

### Fine-Grained Structural Attributes

Fine-grained attributes remain more sensitive:

- Sleeve length: 61.5%
- Neckline: 53.8%

These attributes depend on localized garment regions and are affected by ROI boundary variations.

### High-Level Attributes

Silhouette fit achieves 88.9% agreement, showing stable overall shape perception.

Fashion style achieves 61.1% agreement, indicating sensitivity to ROI quality and visual interpretation.

---

## 6. Limitations

- This experiment evaluates propagation consistency rather than absolute attribute accuracy.
- GT annotations are used only for comparison and joining purposes.
- The matched evaluation set remains limited.
- Category coverage is incomplete.
- Results should be interpreted as diagnostic evidence rather than final production acceptance.

---

## 7. Conclusion

The full-validation experiment confirms the interface between PRD 3.1.1 predicted ROI generation and PRD 3.1.3 attribute extraction.

Predicted ROI outputs can be consumed by downstream attribute modules without requiring GT crop or mask information.

Future improvements should focus on:
1. Improving local region localization quality.
2. Introducing region-specific refinement strategies.
3. Expanding category-balanced validation coverage.
